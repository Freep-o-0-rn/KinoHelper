# KinoHelper 1.553 — автосохранение прогресса каждой серии

**Статус:** тестовая версия. Основана на подтверждённой версии 1.552, которая корректно отображает «Сезон 1 · Серия 3» на реальном плеере.

## Что работает

- Основной плеер `theatre.stravers.live` по-прежнему фиксирует движение HTML5-видео. Для сериалов подключён отдельный скрипт `series-progress-tracker.js`.
- Каждая серия сохраняется отдельно в `chrome.storage.local`, ключ хранилища `kinoSeriesEpisodeProgressV1`. Ключ записи: `series:<id>:<season>:<episode>`.
- Позиция обновляется примерно каждые **5 секунд подтверждённого просмотра**, дополнительно при паузе, ручной перемотке, переключении вкладки и закрытии страницы (по возможности).
- Перед сохранением сервис-воркер сверяет ID сериала основной вкладки и подтверждённые сезон и серию **того же iframe**, откуда пришёл таймкод.
- При смене серии прежнее видео может ещё воспроизводиться — новая серия не получает его таймкод. Отслеживание возобновится после признака смены медиапотока или видеоэлемента.
- Старые сообщения от предыдущей серии игнорируются. URL видеопотока/токены не сохраняются.
- В истории сериала виден прогресс **последней просмотренной серии**, включая номер сезона и эпизода. В отдельной карточке «Последний просмотр» тоже отображается сохранённая серия и время.
- Досмотренные серии сохраняются как завершённые только при подтверждённом событии `ended`; в список продолжения не попадают, если нет других незавершённых эпизодов.
- Данные фильмов остаются в своём прежнем хранилище `kinoPlaybackProgressV1`. Интервал фильмов и кнопка «Продолжить» не изменены. Если сайт сериала использует адрес `/film/<id>`, новое распознавание не должно писать его позицию как фильм при подтверждённой сессии сериала.

## Что пока НЕ включено

**Кнопка «Открыть» у сериала не выбирает автоматически нужную серию и не перематывает её.** Это следующий этап после проверки корректности сохраняемых данных. Автоматическое восстановление пока работает только для фильмов.

## Проверка на реальном сериале

1. Сохрани копию установленной версии 1.552. Распакуй ветку `feature/series-episode-progress-1553` в **ту же папку**, не удаляя расширение. Перезагрузи KinoHelper на `chrome://extensions/`, проверь версию **1.553**.
2. Открой сериал через КиноПомощник. Выбери **Сезон 1 · Серия 3**. Дождись загрузки фильма и смотри не меньше 15–20 секунд.
3. Открой историю: под сериалом должны появиться `Сезон 1 · Серия 3 · 0:XX / ... · N%`.
4. Нажми паузу. Проверь время, затем вручную переключи на **Серия 4**.
5. Дождись запуска нового видео, смотри 15–20 секунд. Теперь под тем же сериалом должен появиться `Сезон 1 · Серия 4` и новая позиция **около начала серии**, а не таймкод из серии 3.
6. Поставь на паузу, закрой вкладку. Открой КиноПомощник снова: карточка последнего просмотра должна показывать **Сезон 1 · Серия 4** с сохранённым временем.
7. Если нужно проверить обе записи в Chrome, в консоли **самого расширения** (не сайта) можно использовать безопасное чтение:

```javascript
chrome.storage.local.get('kinoSeriesEpisodeProgressV1').then(({kinoSeriesEpisodeProgressV1 = {}}) => {
  console.table(Object.entries(kinoSeriesEpisodeProgressV1).map(([key, v]) => ({
    key,
    position: v.position,
    duration: v.duration,
    completed: v.completed
  })));
});
```

Должны существовать отдельные ключи `series:<id>:1:3` и `series:<id>:1:4`. Не присылай полный экспорт хранилища, если в нём есть другие личные данные.

## Возможные ограничения

- Если плеер меняет эпизод без обновления видеоэлемента, источника и событий загрузки, консервативная защита может временно **не сохранять** новый эпизод. Это безопаснее, чем сохранить неверное время. В таком случае пришли скриншот UI и опиши, изменился ли таймкод после переключения.
- При аварийном завершении Chrome последние несколько секунд могут не успеть сохраниться.
- Для сериалов с другим интерфейсом выбора серий, неизвестным доменом iframe или неполной идентификацией запись выключена.
- В истории показывается последний эпизод, а не весь список серий. Хранилище поддерживает отдельные записи каждого просмотренного эпизода.
