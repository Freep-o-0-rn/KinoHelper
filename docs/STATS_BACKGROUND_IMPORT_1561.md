# KinoHelper 1.561 — импорт оценок полностью автоматически

**Ветка:** \`feature/stats-background-import-1561\`, основана на 1.560. В \`main\` не переносилась.

## Что изменилось

В KinoHelper больше не нужно вводить ID профиля, нажимать «Импорт оценок» или ограничиваться 5 страницами за одну операцию.

- Когда Chrome запускается или пользователь открывает «Статистику», расширение автоматически определяет текущий **авторизованный профиль Кинопоиска**.
- Фоновая очередь последовательно обходит все **доступные и распознанные** страницы оценок данного профиля. **Лимита 5 страниц нет.**
- Для снижения нагрузки между страницами установлен интервал **60 секунд**. Chrome может запускать отложенные задачи позже планируемого времени.
- Состояние сохраняется **после каждой страницы**. Можно закрывать Popup, Side Panel или переходить к другим вкладкам — Chrome с открытым браузером продолжает импорт через \`chrome.alarms\`.
- При перезапуске Chrome импорт возобновляется с сохранённой страницы, а не начинает заново.
- Если Кинопоиск возвращает сетевую ошибку, HTTP 429/503 или требует капчу, очередь **приостанавливается** и запланирует повторную попытку с увеличенной паузой. Никакого обхода капчи или ограничений Кинопоиска нет. При необходимости пользователю может потребоваться пройти обычную проверку на сайте.
- После подтверждения последней страницы импорт становится завершённым и **автоматически проверяет обновления раз в 24 часа**, начиная новый цикл с первой страницы. Старые оценки при этом не пропадают.
- Для разных аккаунтов оценки, завершённые страницы и курсор хранятся отдельно. При смене аккаунта текущая очередь переключается на новый.
- Новый интерфейс содержит узкую полосу прогресса, подпись **«X из Y страниц»** (если известно Y), число импортированных оценок и текстовое состояние «Загрузка», «Завершено», «Повторная попытка».
- Ручные кнопки «Обновить оценки известных фильмов» и «Продолжить импорт оценок» удалены: их заменяет фоновый импорт.

## Реализация

- \`stats-import-worker.js\` — фоновой планировщик и очередь. Использует \`chrome.alarms\`, \`chrome.storage.local\`, существующий механизм проверки профиля и обычный \`fetch\` с сессионной авторизацией.
- \`stats-offscreen.html\` + \`stats-offscreen.js\` — изолированный HTML-документ, позволяющий безопасно использовать стандартный DOMParser (он недоступен в Chrome MV3 service worker). Парсер \`stats-profile-import.js\` не выполняет чужие скрипты.
- \`stats-account.js\` — доступен как в обычном UI, так и в service worker.
- \`background.js\` — только подключение планировщика; логика плеера и прогресса не изменена.
- \`stats.js\`, \`popup.html\`, \`sidepanel.html\`, \`stats.css\` — динамический прогресс.
- \`manifest.json\` — добавлены штатные Chrome разрешения \`alarms\` и \`offscreen\`; разрешение \`cookies\` **не запрашивается**.

Новый ключ состояния \`kinoStatsImportJobV2\` хранит ID текущего аккаунта, следующую страницу, число страниц, подтверждённое количество оценок, состояние, текст ошибки и время следующего запуска. При обновлении из версии 1.560 импорт продолжает со страницы, сохранённой в \`kinoStatsProfileImportV1\`.

Существует большой технический предел 20000 страниц для защиты от бесконечного цикла при ошибках пагинации. Это **не лимит 5 страниц и не ограничение одного сеанса**. При необычно большом значении будет выведена ошибка, а не произвольная статистика.

## Как установить

1. Скачай ZIP ветки 1.561.
2. Распакуй и **замени файлы в той же папке**, в которой установлен KinoHelper. **Не удаляй** расширение: при удалении Chrome может очистить его хранилища.
3. На \`chrome://extensions/\` нажми «Обновить». Проверь версию **1.561**.
4. Открой «Статистику»: должен быть определён аккаунт, отображаться прогресс и статус автоматического импорта.
5. Закрой Side Panel/Popup. Через некоторое время снова открой статистику: количество загруженных страниц должно увеличиваться даже без открытой панели, если Chrome запущен и сайт предоставляет данные.
6. После окончания загрузки должна появиться отметка «Импорт завершён». В дальнейшем проверка новых оценок будет происходить автоматически.

## Важные ограничения

- Импорт основан на неофициальной структуре страниц Кинопоиска, которая может изменяться. При ошибке разбора **не записываются неподтверждённые оценки**.
- При капче, отказе доступа или сетевой ошибке нельзя гарантировать загрузку всех страниц; в интерфейсе отображается явное состояние приостановки и причина.
- Chrome может задерживать задачи при экономии энергии или переводе в сон. **Если Chrome полностью закрыт, фоновая загрузка не идёт; она возобновится при следующем запуске.**
- Позиции воспроизведения, история, сохранение раз в **5 секунд**, фильмовые и сериальные показатели времени и оценки не должны измениться.
- После полной загрузки профиля количество **оценок** и число **просмотренных произведений** всё ещё являются разными показателями: оценки не используются для выдумывания времени просмотра.
