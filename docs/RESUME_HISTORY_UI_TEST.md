# KinoHelper 1.546 — прогресс в истории и «Последний просмотр»

Ветка тестирования: `feature/resume-history-ui`. Основа — 1.545 с уже подтверждённым автосохранением таймкода.

## Что добавлено

- Под названием **фильма в истории** появляется тонкая полоса прогресса, точное сохранённое время, длительность и процент. Отображаем только фильмы, у которых есть действительная запись `kinoPlaybackProgressV1` и совпадает ID Кинопоиска.
- **100% и «Просмотрено»** показываются только при `completed=true`, а не из-за округления.
- **Сериалам** не добавляем ложные полосы прогресса: эпизод ещё нельзя идентифицировать автоматически.
- Отдельная карточка **«Последний просмотр»** находится над поиском. Показывает последнее открытое незавершённое видео (фильм или сериал) из истории, его подтверждённый прогресс при наличии, кнопку «▶ Открыть». Завершённые фильмы исключены.
- Если тот же фильм уже открыт для просмотра в активной вкладке, карточка его не дублирует. При возврате к другим вкладкам карточка снова появляется.
- Если фильм/сериал ещё не имеет записанного таймкода, карточка явно сообщает об отсутствии прогресса. Для сериалов — «таймкод серии пока недоступен».
- Записи обновляются по `chrome.storage.onChanged` без закрытия/открытия расширения.
- Существующий список истории, порядок записей, кнопки просмотра и удаления, настройки и «Буду смотреть» не изменяют формат данных.

## Важное ограничение

Кнопка **«▶ Открыть»** открывает прежнюю ссылку фильма/сериала. Автоматической установки `video.currentTime` при возвращении ещё **нет**; это следующий этап, после которого будет корректно использовать название кнопки «Продолжить с ...». Текущая карточка не обещает восстановление таймкода.

## Проверка в Chrome

1. Сохрани резервную копию версии 1.545 и установи файлы ветки в **ту же папку** расширения, не удаляя его.
2. На `chrome://extensions/` перезагрузи КиноПомощник. Версия должна стать **1.546**.
3. Открой в КиноПомощнике фильм, где уже есть сохранённый таймкод. Найди его в **истории**: под названием должны быть полоса прогресса и время (например, `0:52 / 1:32:08 · 1%`).
4. Переключись на другую вкладку: над поиском появится «Последний просмотр» со временем и кнопкой «Открыть». При просмотре этого же фильма карточка не должна дублировать блок «Сейчас смотрите».
5. Посмотри фильм ещё 20–30 секунд. При открытой боковой панели линия прогресса в истории должна обновиться в течение нескольких циклов автосохранения.
6. Закрой вкладку с фильмом. Оставшийся прогресс и карточка должны пережить закрытие вкладки и перезапуск Chrome.
7. Открой сериал из истории — в отдельной карточке он может показываться, но **без выдуманного таймкода серии**.
8. Удали запись фильма из истории. Карточка, зависящая от этой записи, должна перестроиться. Сохранившийся прогресс в `chrome.storage.local` при этом не удаляется.
9. Проверь оба режима: **Popup** и **Side Panel**, светлую и тёмную темы.

## Тестирование кода

```bash
node --test tests/resume-ui.test.cjs
```

Тесты охватывают проценты, завершение, исключение текущей вкладки, сериалы, обновление по storage и кнопку открытия. Без проверки в настоящем Chrome нельзя считать UI полностью подтверждённым.

## Откат

Верни файлы из `feature/resume-autosave-v1` (версия 1.545) в прежнюю папку и перезагрузи расширение. Резервная версия `stable/1.543` тоже сохранена. Не удаляй расширение: иначе браузер может очистить его локальное хранилище.

## Следующая цель

Проверка и реализация **автоматического восстановления таймкода** по сохранённому прогрессу для фильма; далее проверка сезон/серия для сериалов.
