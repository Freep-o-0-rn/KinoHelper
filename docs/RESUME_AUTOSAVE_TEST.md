# KinoHelper 1.545 — автоматическое сохранение прогресса (проверочная версия)

Основа: диагностическая версия 1.544.3 и исправленный список «Буду смотреть» 1.543.

**В этой версии прогресс фильмов сохраняется автоматически. Восстановление таймкода по одной кнопке пока не включено.** Сначала проверяем, что файл прогресса переживает закрытие вкладки и перезапуск браузера. Это убережёт от случайного переноса таймкода на другой фильм/серию.

## Что работает

- После предоставления Chrome разрешения к `theatre.stravers.live` отслеживающий скрипт регистрируется для этого домена (включая iframe) и работает независимо от окна расширения. Регистрация переживает перезапуск Chrome.
- Сохраняет позицию примерно каждые 10 секунд реального воспроизведения, дополнительно при паузе и перемотке; при закрытии вкладки используется последняя успешно записанная позиция.
- Только фильмы, для которых по основной вкладке или существующей сессии расширения удалось уверенно определить ID Кинопоиска. **Сериалы не записываются**, пока не проверена идентичность серии.
- Выбор основного видео отбрасывает элементы без метаданных, с неизвестной длительностью и нулевыми размерами (как второе видео из диагностики).
- Хранилище: `chrome.storage.local`, ключ `kinoPlaybackProgressV1`; данные остаются после перезапуска браузера (но удаление расширения удалит хранилище).
- При подтверждённом событии окончания с достаточной длительностью воспроизведения запись отмечается `completed=true`. Продолжение не должно показывать завершённые записи.
- Ссылки iframe, параметры и токены плеера НЕ сохраняются. В хранилище только ID фильма, название, длительность, позиция, отметка завершения и время обновления.
- При отзыве доступа к домену новые записи блокируются.
- Никаких автоматических перемоток. История, «Буду смотреть», рейтинги и фильтры не меняются.

## Как проверить в Chrome

1. Сохрани резервную копию текущей рабочей папки расширения и распакуй ветку `feature/resume-autosave-v1` в ту же папку. **Не удаляй установленное расширение** — иначе могут потеряться данные и разрешения.
2. Перейди в `chrome://extensions/`, перезагрузи KinoHelper. Убедись, что версия **1.545**.
3. Разрешение к `theatre.stravers.live`, уже предоставленное в 1.544.3, обычно сохраняется. Если доступ отозван, открой «Настройки → Проверить плеер» и разреши доступ один раз.
4. Открой фильм через КиноПомощник и включи видео (желательно после заставки). Если фильм уже открыт при обновлении расширения, обнови вкладку.
5. Смотри примерно **30–40 секунд**. Окно расширения можно закрыть — отслеживание должно продолжаться в фоновом iframe.
6. Открой KinoHelper → **Настройки → СОХРАНЁННЫЙ ПРОГРЕСС → Обновить данные**. Должна появиться запись `Фильм · MM:SS / HH:MM:SS` с позицией примерно текущего просмотра (задержка до ~10 секунд).
7. Поставь видео на паузу, снова нажми «Обновить данные». Позиция должна приблизиться к моменту паузы.
8. Закрой вкладку с фильмом и открой расширение снова. Запись должна сохраниться.
9. Перезапусти Chrome и снова открой настройки. Запись должна остаться. Включение фильма и восстановление таймкода пока выполняются вручную — это следующий этап.
10. Для проверки защиты попробуй включить сериал: сейчас эпизоды НЕ должны попадать в список сохранённых позиций.

## Если записи нет

Проверь, что фильм запущен через KinoHelper; что основная вкладка соответствует фильму с URL вида `/film/<id>/`; что в диагностике найдено движение HTML5-видео; что к iframe `theatre.stravers.live` есть разрешение. Отправь отчёт диагностики и скриншот блока «Сохранённый прогресс». Полные URL плеера с токенами присылать не нужно.

## Тесты

Для Node.js 18+:

```bash
node --test tests/playback-autosave.test.cjs
```

Это тесты логики без настоящего плеера. Совместимость с браузером подтверждается только ручным тестом.

## Безопасный откат

Рабочая версия сохранена в `stable/1.543`, диагностическая — в `feature/resume-playback-probe` (1.544.3), а автосохранение разрабатывается только в `feature/resume-autosave-v1`. При откате верни файлы в **ту же папку** и нажми «Обновить» на странице расширений Chrome. Хранилище `kinoPlaybackProgressV1` старой версией не используется.

**Следующий этап после проверки:** карточка «Продолжить просмотр» и восстановление позиции в фильме. Для сериалов сначала нужно исследовать, как плеер определяет сезон и номер серии.
