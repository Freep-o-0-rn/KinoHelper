# КиноПомощник 1.542 — «Буду смотреть» (тестовая ветка)

Тестируем только ветку `feature/watchlist-v1`. Рабочая ветка `main` остаётся 1.541.

## Функции

- Кнопка **☆ Буду смотреть** в результатах поиска по названию.
- Кнопка **☆ В «Буду смотреть»** для текущего фильма/сериала Кинопоиска и распознанной вкладки просмотра.
- Отдельный блок списка над историей: название, год (при наличии), постер (если доступна допустимая ссылка), действия **▶ Смотреть**, **КП**, **✕**.
- Повторное нажатие закладки снимает её. Повторное добавление того же фильма не создаёт дубль.
- Список сохраняется в `localStorage` расширения по ключу `kinoHelperWatchlistV1`. Состояние сворачивания — `kinoHelperWatchlistCollapsed`.
- История `kinopoiskHistory`, рейтинги, поиск, фильтры и режим Side Panel не изменяют своё поведение.
- **Кнопка «Смотреть»** записывает факт открытия в существующую историю (как и раньше), но **не удаляет фильм из «Буду смотреть»** и не отмечает его досмотренным.
- Список локальный и не синхронизируется с учётной записью Кинопоиска. Пустые/недоступные постеры заменяются иконкой.
- Без новых Chrome permissions и без фоновых запросов ради списка.

## Проверка в Chrome

1. Сохраните копию текущей рабочей папки расширения и локальных данных. **Не удаляйте** рабочее расширение.
2. Получите код ветки `feature/watchlist-v1` и обновите **тот же установленный экземпляр** расширения в той же папке, чтобы не сменить ID и хранилище.
3. Откройте `chrome://extensions/` → **Обновить** на карточке КиноПомощника, проверьте версию **1.542**.
4. Через поиск найдите фильм и нажмите **☆ Буду смотреть** — фильм появляется в списке; повторное нажатие убирает его.
5. Добавьте два разных фильма и сериал. Проверьте сортировку, кнопку **КП**, кнопку **✕** и сворачивание блока.
6. Откройте страницу фильма на Кинопоиске. Убедитесь, что появится кнопка добавления в блоке текущего фильма.
7. Проверьте **▶ Смотреть** из списка: открывается фильм, список остаётся нетронутым, обычная история продолжает работать.
8. Закройте/откройте расширение, затем перезапустите Chrome: «Буду смотреть» должен сохраниться.
9. Переключитесь на Side Panel: список и его состояние должны совпадать с Popup.

## Автотесты

При наличии Node.js 18+ из корня репозитория:

```bash
node --test tests/watchlist.test.cjs
```

Это тесты локального хранилища и кнопки-закладки; они **не заменяют** проверку UI в Chrome.

## Откат

Если обнаружена регрессия, верните сохранённую рабочую папку 1.541 в **тот же каталог** и перезагрузите расширение на `chrome://extensions/`. **Не удаляйте расширение**: удаление может лишить доступа к его локальным данным.

Реализация автосохранения таймкода и «Продолжить просмотр» в эту ветку не входит.
