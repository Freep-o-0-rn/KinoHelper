# KinoHelper 1.562 — подробные оценки и компактная статистика

Тестовая ветка `feature/stats-ratings-ux-1562`. Основана на 1.561, рабочие ветки сохранены отдельно. Основная ветка `main` не изменялась.

## Изменения

### 1. Круговая диаграмма личных оценок 1–10
- Вместо четырёх диапазонов (1–4, 5–6, 7–8, 9–10) теперь **10 отдельных категорий**, от оценки **1** до **10**.
- Каждой оценке назначен свой цвет (градиент от красного для низких до зелёного для высоких).
- Под диаграммой — компактная **легенда в две колонки** с числом оценок по каждой категории, включая нули.
- При наведении или фокусе на цветной сектор появляется детальная подсказка.
- **Средняя оценка** в центре диаграммы и формула расчёта не изменялись; общий счётчик равен сумме всех 10 категорий.
- Личные оценки, уже импортированные в версиях 1.559–1.561, сохраняются и автоматически показываются в новом формате; повторный импорт для нового отображения не нужен.

### 2. Ускорение автоматического импорта
- Интервал между последовательными запросами изменён с **60 секунд до 30 секунд**.
- Используется существующий `chrome.alarms`: в реальном Chrome запланированные задачи могут выполняться позже. Это не фиксированный таймер и не обещание точного времени завершения.
- После ошибок, капчи, HTTP 429/503 и отказов доступа сохраняется **прежняя увеличенная пауза** и автоматические повторы, без обхода защит Кинопоиска.
- Фоновый импорт, сохранение курсора после каждой страницы, перезапуск после закрытия Chrome и ежедневное обновление **не изменялись**.
- Если в 1.561 уже стоял запланированный alarm, одна следующая страница может выполниться по старому графику, остальные будут планироваться с новым интервалом.

### 3. Меньше технической информации
- Убрано длинное пояснение про определение полностью просмотренных сериалов, которое загромождало экран.
- Под диаграммами времени, жанров и оценок остаются только короткие понятные сообщения.
- В профиле объяснение сокращено до одной строки: **«Оценки загружаются автоматически. Можно закрыть панель.»**
- Строка импорта выводит состояние («загружаем», «готово», «временная ошибка») и число найденных оценок; сама полоса показывает прогресс страниц.

### 4. Версия внизу главного экрана
- Под блоком автора на главном экране появился маленький серый номер **v1.562**.
- Номер подставляется автоматически через `chrome.runtime.getManifest().version`; будет верным после обновления `manifest.json`.
- Работает в Popup и Side Panel, не мешает интерфейсу поиска и не отображается в статистике/настройках.

## Установка
1. Скачай ZIP ветки `feature/stats-ratings-ux-1562`.
2. Замени файлы в **уже установленной папке** (не удаляя расширение и не сбрасывая его хранилища).
3. Открой `chrome://extensions/`, нажми «Обновить» и проверь версию **1.562**.
4. Открой статистику: в «Мои оценки» должны быть отдельные цифры **1, 2, 3, …, 10**, а средняя и общее количество оценок должны совпасть с предыдущей версией.
5. Перейди на главный экран и прокрути вниз — версия должна быть внизу под блоком автора.
6. Открой статистику повторно и проверь прогресс фонового импорта. Уже скачанные страницы должны остаться учтёнными.

## Проверки и ограничения

Для локальной проверки:

```bash
node --test tests/stats.test.cjs tests/stats-background-import.test.cjs tests/stats-auto-flow.test.cjs
```

Проверяется распределение оценок 1–10 без потери суммарного количества и средняя, формат версии, синтаксис скриптов и сохранение фоновой очереди. В реальном Chrome новую версию ещё нужно проверить.

Поиск, история, воспроизведение, таймкоды каждые **5 секунд**, реальное время просмотра и импортированный архив оценок не менялись. Предыдущая версия сохранена в `feature/stats-background-import-1561`.

**Примечание:** интервалы Chrome alarms не являются гарантированными. Скорость также зависит от ответа Кинопоиска и сети.
