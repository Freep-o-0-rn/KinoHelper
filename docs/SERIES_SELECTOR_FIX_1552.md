# KinoHelper 1.552 — исправлен выбор сезона и серии

## Что выявила реальная диагностика

У страницы сериала `brogiro.cfd/series/404900/` контролы находятся внутри фрейма `theatre.stravers.live`.

**Точные признаки выбранного эпизода:**

- `button.select__item` с текстом `Сезон 1` — выбранный сезон;
- `button.select__item` с текстом `Серия 1` — выбранный эпизод;
- после переключения та же выбранная кнопка содержит `Серия 2`;
- `button.select__drop-item.active` — активный пункт **раскрытого** меню;
- `div.active` содержит текст **всех** серий, поэтому его нельзя принимать за выбранную серию.

Алгоритм версии 1.550 искал преимущественно `.active` / `aria-selected`, поэтому не видел кнопку сезона. В 1.552 чтение выбранных `select__item` имеет приоритет перед общими эвристиками.

## Изменения

1. Распознавание работает при закрытом и открытом меню; раскрывать его для ежедневной работы не требуется.
2. Строго требуются **один номер сезона и один номер серии**. Если отсутствует хотя бы один или есть конфликт с активным пунктом меню — никакое значение не выдаётся.
3. После ручного переключения серии выбранный номер обновляется автоматически, предыдущий при отсутствии подтверждения очищается.
4. На вкладке **«Сейчас смотрите»** выводится компактная строка `Сезон 1 · Серия 2` при подтверждённом выборе.
5. Временные диагностические кнопки, отчёт и вспомогательные скрипты удалены из Popup и Side Panel. Отдельная ветка диагностики `feature/series-diagnostic-1551` сохранена.
6. Интервал автосохранения **фильмов — 5 секунд** и рабочее восстановление фильма остались прежними. Для сериалов автоматический таймкод **ещё не сохраняется и не восстанавливается**: для безопасной привязки нужно подтвердить правильность выбора серии на реальной странице.

## Проверка 1.552

1. Сохрани копию рабочей папки, распакуй файлы из `feature/series-selector-fix-1552` **в ту же папку** расширения. Не удаляй само расширение.
2. Перезагрузи через `chrome://extensions/`. Версия: **1.552**.
3. Открой `brogiro.cfd/series/404900/` через КиноПомощник. Выбери **Сезон 1, Серия 1**.
4. Открой КиноПомощник в Side Panel: в «Сейчас смотрите» должна появиться строка **Сезон 1 · Серия 1**, даже если меню в плеере закрыто.
5. Выбери в самом плеере **Серию 2**. Строка в боковой панели должна измениться на **Сезон 1 · Серия 2** в течение нескольких секунд.
6. Переключи сезон, например на сезон 2, и выбери серию. Проверь оба номера.
7. Убедись, что при обычном фильме строка сезона/серии не появляется.
8. Проверь «Продолжить» у фильма с сохранённым таймкодом — оно должно работать как в 1.549.

### Ожидаемый результат

При неверных или неполных данных строка не появляется вместо показа ложного номера. Если всё определяется правильно, следующий этап — постоянное сохранение прогресса отдельно для `ID сериала + сезон + серия`, затем безопасная автоматическая установка этих селекторов и таймкода.

### Автотесты

```bash
node --test tests/episode-identification.test.cjs
```

Добавлены случаи по фактическим меткам плеера до и после переключения, открытое/закрытое меню, противоречащие значения, отсутствие сезона, очистка устаревшей записи.

**Ограничение:** прохождение синтетических тестов не доказывает работу с настоящим плеером; её нужно подтвердить проверкой Side Panel.
