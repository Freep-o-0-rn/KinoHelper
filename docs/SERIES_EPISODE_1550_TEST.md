# KinoHelper 1.550 — автоматическое распознавание сезона и серии

Ветка: `feature/series-episode-identification-1550`. Основа: 1.549, включая пятсекундный прогресс фильмов, автоматическую перемотку и карточку последнего просмотра.

## Что добавлено

- В существующем блоке **«Сейчас смотрите»** появляется компактная строка **«Сезон N · Серия M»**, **только если оба номера определены однозначно**. Новых диагностических панелей нет.
- Скрипт `episode-detector.js` автоматически запускается в доступных фреймах `brogiro.cfd` и `theatre.stravers.live`, считывает только явно заданные номер сезона и эпизода из URL или выделенных элементов интерфейса.
- Если два доступных фрейма показывают **разные** номера серии, информация скрывается до устранения противоречия.
- После переключения серии старая информация удаляется, если новое значение не подтверждено. Записи устаревают через 20 секунд, а открытая боковая панель перепроверяет их.
- Перед сохранением распознанных номеров сервис-воркер подтверждает, что активная вкладка действительно относится к сериалу, открытому на известном сайте.
- Сезон и серия хранятся **только в `chrome.storage.session`**. В базе завершённых/незавершённых просмотров пока ничего не меняется.
- URL плеера, видеопотоки и токены не передаются и не сохраняются.
- Время фильмов продолжает сохраняться каждые **5 секунд**, их продолжение по одной кнопке сохраняется.
- Автоматическая перемотка сериалов **пока не включена**, чтобы не перепутать эпизоды с одинаковой продолжительностью.

## Проверка в Chrome

1. Сохрани текущую папку 1.549. Обнови файлы **в том же каталоге** расширения из ветки `feature/series-episode-identification-1550` и перезагрузи КиноПомощник на `chrome://extensions/`. Номер версии — **1.550**.
2. Открой **сериал** через КиноПомощник. Выбери конкретные сезон и серию в плеере и начни воспроизведение.
3. В боковой панели КиноПомощника проверь блок «Сейчас смотрите». Если сайт предоставляет явно выбранные номера, появится строка вида `Сезон 2 · Серия 4`. После выбора другой серии строка должна обновиться.
4. Если строка **не появилась**, не считай это ошибкой сохранения фильма. Это означает, что текущий интерфейс плеера не предоставил достаточно явных признаков серии для безопасного определения. Пришли скриншот плеера с **видимым переключателем сезонов и серий**; по нему подберём точный обработчик этого интерфейса.
5. Проверь, что для обычного фильма строка сезона/серии не отображается и что кнопка «Продолжить» по-прежнему перематывает фильм на сохранённую позицию.
6. Проверь обычную Popup-версию и Side Panel — результат должен совпадать.

## Автотесты

```bash
node --test tests/episode-identification.test.cjs
```

Тесты покрывают распознавание явных меток, параметры URL, конфликт источников, очистку устаревшего значения и защиту от неправильного сайта. Это не заменяет реальную проверку интерфейса выбранного видеоплеера.

## Ограничения

Нельзя гарантировать распознавание на `theatre.stravers.live`, пока не проверена структура реального селектора сезонов и эпизодов. Если там только неразмеченные цифровые кнопки (например, «1», «2», «3»), скрипт **не угадывает** номера. Прежде чем включать сохранение времени для сериалов, требуется однозначно подтвердить выбранный эпизод на реальном сайте.

## Откат

Рабочая 1.549 сохранена в `feature/resume-save-1549`. Для отката верни её файлы в **существующую** папку и обнови расширение на `chrome://extensions/`. Не удаляй расширение, чтобы не потерять локальную историю и позиции.
