# KinoHelper 1.544 — «Продолжить просмотр», этап 1: проверка видеоплеера

## Защита рабочей версии

- `stable/1.543` — сохранена последняя подтверждённая рабочая версия «Буду смотреть».
- `feature/resume-playback-probe` — экспериментальная версия 1.544.
- `main` не меняется до завершения проверки.
- В 1.544 **не** сохраняется и **не** восстанавливается таймкод.

## Запуск проверки

1. Обнови файлы установленного экземпляра KinoHelper из ветки `feature/resume-playback-probe` в **той же папке**, сохранив резервную копию 1.543. Не удаляй установленное расширение (иначе можно потерять доступ к его локальным данным).
2. Открой `chrome://extensions/`, обнови расширение. В карточке будет версия **1.544**.
3. Открой фильм через КиноПомощник на обычном сайте просмотра, включи видео. Не ставь его на паузу.
4. Открой боковую панель KinoHelper → **Настройки → ПРОДОЛЖИТЬ ПРОСМОТР — ДИАГНОСТИКА → Проверить плеер**.
5. Через ~3 секунды появится результат. Нажми **Копировать отчёт** и отправь текст сюда.
6. Для сериалов отдельно открой конкретную серию, переключи на другую и повтори проверку. Запиши, изменилась ли серия в самом плеере и появилась ли новая вкладка.
7. В отчёте перечисляются только домены фреймов, **без полных URL, токенов или видеопотоков**.

### Интерпретация

- **Видео найдено, движение +3 с, известная длительность** — можно проектировать пассивное сохранение `currentTime` с привязкой к фильму.
- **Видео найдено, время не меняется** — проверь, что видео не стоит на паузе; на некоторых плеерах `currentTime` недоступно.
- **HTML5-видео не найдено, но есть неизвестный iframe-домен** — нужно отдельно изучить домен плеера и при необходимости запросить **узкое разрешение**. Пока никакие новые сайты не запрашиваются.
- **Видео не найдено вообще** — требуется дополнительная диагностика DOM или нестандартного плеера.

### Почему два замера

Одного значения `currentTime` недостаточно: оно может относиться к скрытому видео, рекламному ролику или остановленному элементу. Второй замер помогает подтвердить, что время действительно движется.

## После успешной проверки

1. Добавить content script **только на подтверждённые домены**, без `<all_urls>`.
2. Сохранять `mediaId + тип + серию + currentTime + duration` в `chrome.storage.local`; не привязывать прогресс к ID вкладки (вкладка может быть закрыта).
3. Сохранять с разумным интервалом, а также при паузе/перемотке. Отсеивать короткие запуски, рекламу и пустые видео.
4. Реализовать проверку идентичности серии до автоматического восстановления позиции.
5. Добавить отдельные карточки «Продолжить просмотр», не дублировать текущую вкладку, скрывать действительно завершённые фильмы.

## Проверки кода

Из корня репозитория с Node.js:

```bash
node --test tests/watchlist.test.cjs tests/player-probe.test.cjs
```

Автотесты проверяют формат диагностики и защиту данных. Они **не заменяют** тест с реальным видеоплеером.
