# KinoHelper 1.560 — автоматическое определение профиля Кинопоиска

Ветвь: \`feature/stats-auto-account-1560\`. Основа: 1.559. \`main\` и ранее работающая 1.558 не изменены.

## Что изменилось

- При открытии статистики расширение **автоматически определяет, выполнен ли вход в Кинопоиск, и определяет ID текущего аккаунта**.
- Поле ручного ввода ID заменено компактным статусом \`Вход выполнен · профиль №…\` и кнопкой **↻** для повторной проверки.
- Сразу после подтверждения профиля запускается **автоматический импорт до пяти страниц личных оценок**. Его прогресс сохраняется. Новый автоматический запуск для того же ID ограничен интервалом **1 час**, чтобы не перегружать Кинопоиск; кнопка **«Продолжить импорт оценок»** работает без этого ожидания.
- Если вошли в другой аккаунт, статистика оценок переключается на **отдельное хранилище по новому ID**. Старые данные не удаляются и не смешиваются.
- Если вышли из аккаунта, импорт блокируется; прежние данные сохраняются. Если личный профиль **не удалось проверить** (капча, ошибка сети, смена разметки), автоимпорт не запускается по старому сохранённому ID.
- Для подтверждённых новых оценок KinoHelper повторно проверяет личный профиль до привязки оценки к конкретному ID; при недоступной проверке оценка попадает в изолированную локальную область без привязки к личности.

## Как определяется ID

Используются только штатные запросы **с уже имеющимся разрешением на \`https://www.kinopoisk.ru/*\`**, с \`credentials:'include'\`. Расширение не читает напрямую cookie, не запрашивает пароль, не перехватывает токены, **не требует разрешения \`cookies\`**.

1. \`https://www.kinopoisk.ru/mykp/\`. Если Кинопоиск направил личный раздел на \`/user/<id>/\`, это явное свидетельство ID владельца.
2. Резерв: \`https://www.kinopoisk.ru/mykp/folders/1/\`. Ищется встроенное в личную страницу \`getUserId = function () { return <id>; }\`.
3. Другие домены, профиль другого пользователя, капча или отсутствие явного доказательства **не принимаются**.

Этот механизм основан на открытом проекте [demrom/kinopoisk-to-imdb](https://github.com/demrom/kinopoisk-to-imdb), где автодетект реализован в \`kinopoisk/ratings.py\`. **Он не является официальным публичным API Кинопоиска**, поэтому работоспособность зависит от текущего формата ответов Кинопоиска.

## Что не изменено

- Учёт фактического времени просмотра отдельно для фильмов и сериалов.
- Автосохранение позиции и восстановление серий каждые **5 секунд**.
- История, поиск, жанры, рейтинг, кнопка «Последний просмотр».
- Данные старых версий; никакое удаление/перезапись локальной истории не делается.

## Проверка на своём Chrome

1. Не удаляя установленное расширение, заменить файлы распакованным ZIP 1.560 и нажать «Обновить» в \`chrome://extensions/\`.
2. Убедиться, что на Кинопоиске выполнен вход. Открыть KinoHelper → **Статистика**.
3. Должно появиться **«Вход выполнен · профиль №…»**, затем статус загружаемых страниц, если личная страница оценок распознана.
4. Сравнить ID с адресом собственного профиля, проверить среднюю оценку и количество оценок.
5. Если появился статус «не удалось подтвердить профиль», открыть личный раздел Кинопоиска в обычной вкладке, проверить авторизацию и нажать **↻**.
6. После успешной проверки перезагрузить Popup/Side Panel. Автоимпорт не должен бесконечно повторять запросы при каждом открытии.
7. Выйти из Кинопоиска и нажать ↻: импорт должен отключиться, но уже полученные оценки и время просмотра не удаляются.
8. При наличии второго тестового аккаунта проверить, что переключение между аккаунтами не показывает чужую оценку как свою.

## Ограничения

- Чтение личных страниц и HTML списка оценок — **неофициальный механизм**. Проверки выполнены на синтетических ответах и моделях браузерного окружения. Поведение **в реальном Chrome с текущей сессией пользователя нужно проверить**.
- Если Кинопоиск запросит капчу или поменяет HTML, расширение показывает диагностический статус и не приписывает аккаунту неподтверждённые данные.
- Первый запуск подтягивает только **до пяти страниц**. Остальные страницы добавляются при следующих запусках с интервалом или вручную по кнопке «Продолжить импорт оценок».
- Старые оценки, которые в 1.558 были сохранены без известного профиля, не присваиваются произвольному аккаунту; их можно заново подтвердить через импорт или «Обновить оценки известных фильмов».
